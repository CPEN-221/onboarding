Getting Started with Java

Preparing for CPEN 221 in Three Segments

Set up your tools and workflow

Use these guides to establish the same development environment and project workflow used in CPEN 221. Start with installation, then follow the guides in order if the command line, build tools, or Git are new to you.

  1. Guide 1 Software to Install Install and verify Java 25, Git, VS Code, and the project-supplied Gradle wrapper on macOS, Linux, or Windows.
  2. Guide 2 Using the Command Line Interface Navigate a project, read paths and commands, operate on files carefully, and preserve useful diagnostic output.
  3. Guide 3 Installing and Using Visual Studio Code Configure Java, Gradle, Git, testing, debugging, and the integrated terminal without hiding the project build.
  4. Guide 4 The Build Process and Tools Follow Java source through compilation, testing, execution, and packaging with the Gradle wrapper and JUnit.
  5. Guide 5 Git and GitHub Record coherent commits, synchronize a remote repository, work on a branch, and recover changes deliberately.

Learn or refresh Java

Begin with the first segment if Java is new to you. If the material is familiar, predict the examples and use the practice to decide where to spend time.

  1. Segment 1 Running Java Programs Run, trace, and repair a small Java 25 program before translating it to the form used in course projects.
  2. Segment 2 Objects, State, and References Construct objects and trace mutable state, aliases, reassignment, identity, and null references.
  3. Segment 3 Iteration, Collections, and Interfaces Traverse values, choose collection contracts, and combine behaviour through interfaces and composition.

What you need

The readings work without JavaScript. Begin with Software to Install, then use the downloadable examples to check the complete toolchain.
