Getting Started with Java

Preparing for CPEN 221 in Three Segments

How to use these segments

Begin with the first segment if Java is new to you. If the material is familiar, predict the examples and use the practice to decide where to spend time.

  1. Segment 1 Running Java Programs Run, trace, and repair a small Java 25 program before translating it to the form used in course projects.
  2. Segment 2 Objects, State, and References Construct objects and trace mutable state, aliases, reassignment, identity, and null references.
  3. Segment 3 Iteration, Collections, and Interfaces Traverse values, choose collection contracts, and combine behaviour through interfaces and composition.

What you need

The readings work without JavaScript. To run the downloadable examples, install a Java 25 JDK and use a terminal. Each example directory includes the exact commands and observed output.
