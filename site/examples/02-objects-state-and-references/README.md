# Objects, state, and references

Compile the examples with Java 25:

```bash
javac -Xlint:all *.java
```

Run the two successful traces:

```bash
java ArrivalBoardDemo
java ReassignmentDemo
```

`NullReferenceFailure` deliberately produces `NullPointerException` after compiling
successfully. Validation observations are recorded in the repository `STATUS.md`.
