# Build Process and Tools Companion Project

This project contains the complete Java 25 source and JUnit 6.1.3 tests used in the
preparation guide. The checked-in Gradle wrapper pins Gradle 9.6.1.

From this directory, run:

```sh
./gradlew test
./gradlew run
./gradlew build
```

In Windows PowerShell, replace `./gradlew` with `.\gradlew.bat`.
